# SEFAZ-TO — Central de Aprovação

Portal inteligente de preparação para concursos da SEFAZ-TO.

## MVP

- Dashboard de desempenho
- Edital verticalizado
- Banco e geração de questões
- Upload de PDF
- Simulados
- Caderno de erros
- Revisão adaptativa
- Plano diário inteligente

## Stack

- React
- Vite
- Supabase
- Vercel
- OpenAI API

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy

O projeto foi estruturado para deploy contínuo pela Vercel conectado ao branch `main`.
